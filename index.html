Missão: Desenvolva o sistema de notas e boletins da escola!

Modo Desenvolvedor: O código pronto não será entregue. Leia o EXEMPLO BRANCO com atenção, deduza a lógica e digite o SEU CÓDIGO VERDE no Laboratório!

Acessar Laboratório Virtual

Fase 1: Identificação (Variáveis)

1

Registrando o Aluno

A primeira etapa é perguntar o nome do estudante. Vamos usar o comando de entrada de dados prompt.

EXEMPLO: var cliente = prompt("Nome do cliente?"); AGORA VOCÊ: Crie a variável 'aluno' e use o prompt para perguntar "Qual o nome do aluno?".
2

Disciplina (Strings)

Textos puros precisam sempre de aspas! Registre qual é a matéria que estamos avaliando.

EXEMPLO: var curso = "Matemática"; AGORA VOCÊ: Crie a variável 'disciplina' e guarde o texto "Lógica de Programação".
3

O Ano Letivo

Vamos guardar a série do aluno. Também é um texto (String).

EXEMPLO: var periodo = "Manhã"; AGORA VOCÊ: Crie a variável 'turma' recebendo o texto "1º Ano do Ensino Médio".
4

Mensagem de Abertura

Use o comando alert e o sinal de + para juntar o seu texto com a variável disciplina.

EXEMPLO: alert("Bem-vindo ao curso de " + curso); AGORA VOCÊ: Faça um alert dizendo "Sistema de Notas da disciplina de " + disciplina.
Página 1

Fase 2: Registro de Notas (Numbers)

5

Nota do 1º Bimestre

Valores numéricos NUNCA levam aspas. Se colocar aspas, o computador não consegue fazer a conta depois!

EXEMPLO: var bimestre1 = 9; AGORA VOCÊ: Crie a variável 'n1' recebendo o número 7.
6

Nota do 2º Bimestre

Vamos registrar a segunda nota do ano.

EXEMPLO: var bimestre2 = 6; AGORA VOCÊ: Crie a variável 'n2' recebendo o número 8.
7

Nota do 3º Bimestre

O aluno foi um pouco pior neste bimestre.

EXEMPLO: var bimestre3 = 4; AGORA VOCÊ: Crie a variável 'n3' recebendo o número 5.
8

Nota do 4º Bimestre

Última nota regular do ano.

EXEMPLO: var bimestre4 = 10; AGORA VOCÊ: Crie a variável 'n4' recebendo o número 6.
9

Ponto Bônus

O aluno participou das aulas de laboratório e ganhou um bônus. (Use ponto, não vírgula, para números quebrados).

EXEMPLO: var extra = 0.5; AGORA VOCÊ: Crie a variável 'bonus' recebendo o número 1.5.
Página 2

Fase 3: O Cérebro Matemático

10

Somando as Notas

O computador sabe fazer matemática pesada. Peça para ele somar as 4 notas e guardar na memória.

EXEMPLO: var total = b1 + b2 + b3 + b4; AGORA VOCÊ: Crie a variável 'somaNotas' que recebe a soma de n1 + n2 + n3 + n4.
11

Adicionando o Bônus

Vamos pegar a soma que acabamos de fazer e adicionar o bônus nela mesma.

EXEMPLO: total = total + extra; AGORA VOCÊ: Atualize 'somaNotas' (sem usar o var) dizendo que ela é igual a ela mesma + o 'bonus'.
12

O Cálculo da Média (Divisão)

Para achar a média, precisamos dividir (usando a barra /) o total por 4.

EXEMPLO: var mediaFinal = total / 4; AGORA VOCÊ: Crie a variável 'media' que recebe a 'somaNotas' dividida (/) por 4.
13

Aviso Silencioso (Console)

Mande o resultado para o console do desenvolvedor (F12) para verificar se o cálculo deu certo.

EXEMPLO: console.log("A média é: " + mediaFinal); AGORA VOCÊ: Faça um console.log avisando "Média calculada: " + media.
14

Mostrando a Média ao Aluno

Use o alerta para o usuário ver o próprio desempenho!

EXEMPLO: alert("Sua média final foi: " + mediaFinal); AGORA VOCÊ: Dê um alert dizendo "A média final do aluno " + aluno + " foi " + media.
Página 3

Fase 4: O Conselho de Classe (If / Else)

Chegou a hora da máquina tomar a decisão sozinha baseada nas regras da escola!

15

Preparando o Status

Crie uma variável vazia. A inteligência artificial do sistema vai preenchê-la logo abaixo.

EXEMPLO: var resultado = ""; AGORA VOCÊ: Crie a variável 'status' recebendo aspas vazias "".
16

Condição 1: A Aprovação Direta

Para passar direto, a média tem que ser Maior ou Igual (>=) a 7. Abra o caminho verdadeiro com a chave {.

EXEMPLO: if (nota >= 7) { AGORA VOCÊ: Inicie o teste: if (media >= 7) {
17

O Sucesso!

O que acontece se ele tiver nota 7 ou mais? Escreva os comandos e feche a chave }.

EXEMPLO: resultado = "Passou"; alert("Parabéns!"); } AGORA VOCÊ: status = "APROVADO"; alert("Parabéns! Você passou direto!"); }
18

Condição 2: A Recuperação (Else If)

E se não tirou 7? Vamos testar se a média é pelo menos Maior ou Igual (>=) a 5. Abra a chave { de novo.

EXEMPLO: else if (nota >= 5) { AGORA VOCÊ: Continue o teste: else if (media >= 5) {
19

A Segunda Chance

Alerte o aluno que ele está de recuperação e feche a chave }.

EXEMPLO: resultado = "Quase"; alert("Faça a prova de recuperação."); } AGORA VOCÊ: status = "RECUPERAÇÃO"; alert("Você tem uma segunda chance!"); }
Página 4
20

Condição 3: A Reprovação (Else)

Se o aluno não tirou nem 7 e nem 5, só sobra uma opção. Não precisa testar, basta usar o else!

EXEMPLO: else { resultado = "Falhou"; alert("Fim da linha."); } AGORA VOCÊ: else { status = "REPROVADO"; alert("Infelizmente, você reprovou por nota."); }

Fase 5: Frequência Escolar

21

Contabilizando Faltas

Nem só de notas vive o aluno. Peça ao professor para digitar as faltas.

EXEMPLO: var ausencias = prompt("Faltou quantas vezes?"); AGORA VOCÊ: Crie a variável 'faltas' perguntando num prompt: "Total de faltas no ano:"
22

Teste de Limite

Vamos criar um novo IF solto. Se as faltas passarem de 25, ele perde o ano instantaneamente.

EXEMPLO: if (ausencias > 25) { AGORA VOCÊ: Inicie o novo teste: if (faltas > 25) {
23

A Sentença das Faltas

Se o teste acima for verdadeiro, nós substituímos o status antigo por Reprovado (mesmo que ele tivesse tirado nota 10!).

EXEMPLO: resultado = "Reprovado por Falta"; alert("Faltou demais!"); } AGORA VOCÊ: status = "REPROVADO POR FALTA"; alert("Atenção: Aluno reprovado por excesso de ausências."); }
Página 5

Fase 6: O Boletim Final

24

Montando o Documento

Para não fazer um "alert" desorganizado, vamos guardar todos os dados processados numa String longa. O \n serve para pular de linha!

EXEMPLO: var doc = "Nome: " + nome + "\nResultado: " + resultado; AGORA VOCÊ: Crie a var 'boletim' e junte: "ALUNO: " + aluno + "\nMÉDIA: " + media + "\nSTATUS: " + status
25

A Impressão Oficial!

Dispare a sua variável pronta num Alerta final.

EXEMPLO: alert("== DOCUMENTO ==\n" + doc); AGORA VOCÊ: Dê o último alert juntando o texto "=== BOLETIM OFICIAL ===\n" com a variável 'boletim'!
