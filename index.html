Fase 1: Calibrando o GPS

1

O Motorista do Google

O sistema precisa registrar quem vai dirigir o carro do Street View. Use o comando prompt para perguntar.
// 1. Identificação do Funcionário
var motorista = prompt("Acesso Google Maps. Qual o nome do motorista?");
2

Definindo o Alvo (String)

Variáveis de texto devem ficar entre aspas. Defina a nossa cidade-alvo capixaba.
// 2. Cidade Alvo
var local = "Sítio Histórico de Muqui";
3

Bateria das Câmeras (Number)

Números não levam aspas. A bateria da câmera 360 graus do teto do carro começa em 100%.
// 3. Energia do Equipamento
var bateria = 100;
Página 1

Fase 2: O Mapeamento Inicial

4

Rota Turística (Array)

Para guardar vários lugares mapeados em uma variável só, usamos uma Lista (Array) com colchetes [ ].

Você acabou de tirar fotos em alta resolução da Estação e da Igreja Matriz. Registre:

// 4. Locais Fotogrados Inicialmente
var mapeado = ["Estação Ferroviária", "Igreja Matriz São João Batista"];
5

O Folclore (Push)

O carro do Google achou a rota do Carnaval! Use o comando .push() para injetar esse dado na lista.

Mande a Praça do Boi Pintadinho direto para o banco de dados da lista:

// 5. Adicionando ao Array
mapeado.push("Praça do Boi Pintadinho");
6

Desgaste da Câmera (Matemática)

Fotografar centenas de casarões históricos gasta energia. O computador resolve a subtração e atualiza a variável.
// 6. Gasto de Bateria
bateria = bateria - 20;
7

Painel do Carro (Saída de Dados)

Vamos usar o alert com o sinal de + para juntar a nossa mensagem com os dados das variáveis!
// 7. Status em Tempo Real
alert("Mapeamento inicial em " + local + " fluindo bem. Bateria em: " + bateria + "%");
Página 2

Fase 3: Parada Estratégica

8

O Mercado Regional (Push)

O motorista parou para mapear o Mercado Regional dos Vales e Café.

Adicione este ponto turístico importante à nossa lista:

// 8. Mapeando o Mercado
mapeado.push("Mercado Regional dos Vales e Café");
9

Recarga Rápida (Soma)

Enquanto o carro mapeava o Solar do Lagarto, aproveitamos para recarregar as baterias.

Some 15% à bateria atual do equipamento:

// 9. Recarregando
bateria = bateria + 15;
10

Verificando a Lista (Console)

Vamos usar o console.log para verificar silenciosamente, na área de desenvolvedor, se a lista está sendo alimentada corretamente.
// 10. Verificação do Array
console.log("Locais já mapeados: ", mapeado);
Página 3

Fase 4: Raciocínio Espacial

11

Rua Estreita (Prompt)

A inteligência do sistema pergunta ao motorista se ele encontrou um obstáculo histórico pela frente, como as calçadas de pedra do Sítio Histórico.

Faça a pergunta e peça para responder "sim" ou "nao":

// 11. O Obstáculo
var ruaEstreita = prompt("A rua dos casarões está muito estreita para o carro? (sim/nao)");
12

A Decisão Lógica (If / Else)

O Google possui mochilas com câmeras chamadas "Trekker" para ruas que carros não entram. Teste a variável com duplo igual (==).

Preste muita atenção nas chaves e parênteses do código abaixo:

// 12. Condição de Rota
if (ruaEstreita == "sim") {
    alert("O Carro parou. Modo câmera de mochila (Trekker) ativado!");
} else {
    alert("Perfeito. O carro avançou pelo calçamento de pedra!");
}
13

Gasto Final (Subtração)

Mapear todo o restante do casario consumiu grande parte da energia.
// 13. Gasto Final de Bateria
bateria = bateria - 60;
Página 4
14

Verificação de Segurança (If / Else)

Antes de fazer o upload, precisamos checar se a bateria não zerou ou ficou negativa durante a operação.

Verifique se a bateria é maior que 0:

// 14. Checagem de Sistema
if (bateria > 0) {
    alert("Bateria ok. Preparando para enviar arquivos.");
} else {
    alert("Atenção: Sistema desligou por falta de energia!");
}
15

Enviando para os Servidores

A última etapa do seu código. Usamos o \n dentro do texto para criar uma quebra de linha visualmente bonita.

Junte todas as variáveis para criar a janela de sincronização final:

// 15. Conclusão da Missão
alert("=== UPLOAD CONCLUÍDO ===\nMotorista: " + motorista + "\nImagens Salvas: " + mapeado + "\nBateria Restante: " + bateria + "%\nSincronizando com o Google Maps...");
